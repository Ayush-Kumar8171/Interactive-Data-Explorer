# Interactive Data Explorer

This is a React application that fetches data from the PokeAPI and allows users to search and filter through the first 150 Pokémon.

## Features

- Fetches the first 150 Pokémon with detailed information including name, image, types, and ID.
- Real-time search functionality to filter Pokémon by name.
- Dropdown filter to filter Pokémon by type (e.g., Fire, Water, Grass).
- Responsive design that works on both desktop and mobile devices.
- Styled using Tailwind CSS for a modern and attractive UI.
- Proper loading and error states.
- Reusable components for maintainability.

## Technologies Used

- React with functional components and hooks
- Tailwind CSS for styling
- PokeAPI for Pokémon data

## How to Run

1. Install dependencies:
   ```
   npm install
   ```
2. Start the development server:
   ```
   npm start
   ```
3. Open your browser and navigate to `http://localhost:3000`.

## Deployment

You can deploy this project using free hosting services like Vercel, Netlify, or GitHub Pages.
